# manual/

Tier C jars — mods that cannot be resolved through packwiz (Modrinth or
CurseForge) and are installed by hand instead. This folder's *contents* are
deliberately untracked (see `.gitignore`); this file is the one exception.

`docs/exceptions-register.md` is the authoritative record of what belongs
here, why, and how to re-obtain it. If a jar shows up in this folder without
a row there, it shouldn't be here.
